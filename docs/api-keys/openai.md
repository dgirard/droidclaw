# OpenAI API Key

Direct access to GPT models (GPT-4o, GPT-4o mini, o1, o3).

## Get a Key

1. Go to [platform.openai.com](https://platform.openai.com/)
2. Create an account or sign in
3. Go to **API Keys** ([platform.openai.com/api-keys](https://platform.openai.com/api-keys))
4. Click **Create new secret key**
5. Copy the key (starts with `sk-...`)

## Pricing

- **Free tier**: $5 credit for new accounts
- **Pay-as-you-go**: add credit via billing settings
- See [openai.com/pricing](https://openai.com/pricing) for per-model rates

## Configure in DroidClaw

- **Onboarding**: select "OpenAI" as provider, paste the key
- **Settings > Provider**: change key later
